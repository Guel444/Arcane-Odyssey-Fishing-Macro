## 📖 About

Arcane Odyssey Fishing Macro is a lightweight Windows application that automates repetitive fishing actions, making long fishing sessions easier.

It is designed to be simple to configure while remaining efficient.

---

## ✨ Features

- 🎣 Automatic fishing
- ⚡ Lightweight and fast
- 🎛️ Simple interface
- ⚙️ Adjustable settings
- 🖥️ Windows support
